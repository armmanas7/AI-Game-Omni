Vesper 是一款第一人称异星探索游戏。你可以穿行于森林、沙漠和发光洞窟，观察动植物，记录标本，调查遗迹，也可以收集补给、制作工具，建立自己的探索返回点。游戏使用 TypeScript 和 Three.js 开发，包含原创模型，并在开发过程中使用了 AI 辅助。游戏运行本身不需要 AI 账号或模型 API。

## 在电脑上开始

保留完整项目文件夹，双击 **Launch Vesper.command**。浏览器会打开本地游戏。需要已安装 Node.js，建议使用 22.12 或更新版本。游戏运行时请保持终端窗口打开；结束后按 Control+C 关闭服务器。

也可以在项目文件夹中运行：

```sh
npm start
```

不要直接双击 `dist/index.html`。游戏需要通过本地服务器打开。GitHub 项目和发行压缩包包含游戏素材；如需重新构建，请运行 `npm ci` 和 `npm run build`。

## 选择语言

在首页选择 **English** 或 **简体中文**。探索途中也可以在暂停菜单的设置中切换。图鉴内容、操作提示、制作要求和触屏按钮会一同切换，不会重置研究进度或背包。语言选择会保存在浏览器中，导出的存档也包含语言设置。

## 常用操作

| 操作 | 按键 |
|---|---|
| 移动 | W / A / S / D |
| 调整视角 | 鼠标，也可使用方向键 |
| 跑步 / 跳跃 | Shift / Space |
| 扫描标本、线索或已解锁的遗迹 | 按住 E |
| 收集补给 / 修复探针 | F |
| 背包与制作 | B |
| 勘测脉冲 | Q |
| 野外图鉴 / 勘测地图 | J / M |
| 暂停 / 释放鼠标 | Esc |
| 返回着陆点 | R |
| 拍照模式 / 保存照片 | P / O |

设置中可以选择“点击移动”：点击空地让角色前往，再按住鼠标右键拖动调整视角。遇到障碍物时角色会停止，需要选择附近空地或手动绕行。

## 为什么按 E 没有完成扫描？

- **需要按住。** 瞄准标本，保持约一秒，等进度条填满；调查遗迹需要稍久一些。轻按一次不会完成扫描。
- **距离太远或视线被挡住。** 目标卡会提示靠近或绕开障碍物。右下方仪表显示当前扫描范围。
- **这一个体已经记录。** 再次扫描同一个对象不会重复获得奖励；可以继续寻找其他个体。
- **遗迹尚未解锁。** 先扫描周围三条不同的线索，再返回中央遗迹。重复扫描同一条线索不算新的线索。
- **这是补给或探针。** 请靠近至 5 米以内，面向目标并按 F。修复探针还需要背包中有足够材料。
- **这是装饰景物。** 并非所有树木、石头或植物都属于图鉴标本。按 Q 可以标出附近尚未记录的标本和线索。

## 收集与制作

补给箱提供回收合金，树脂沉积物提供荧光树脂，晶体矿点提供导电晶体。每处可收集资源提供 3 个材料；背包最多携带 60 件物品。采集后会保存记录，不会通过重新载入重复获得材料。

| 用途 | 所需材料 | 效果 |
|---|---|---|
| 制作脉冲电池 | 2 个导电晶体 + 1 个荧光树脂 | 在背包中使用，立即释放一次勘测脉冲 |
| 制作勘测信标 | 2 个回收合金 + 1 个导电晶体 + 1 个荧光树脂 | 部署在干燥空地，在背包中返回该位置 |
| 修复勘测探针 | 2 个回收合金 + 1 个导电晶体 | 首次修复获得 55 研究经验，并标出一处补给箱 |

同一时间只能部署一个信标。回到信标 5 米以内，背包有空位时可以收回并再次使用。如果背包已满，可以制作、使用或丢弃多余物品，为新材料腾出空间。制作按钮会显示缺少的材料。

## 在手机上体验

直接打开[在线游戏](https://armmanas7.github.io/AI-Game-Omni/)即可游玩，无需安装。新版手机界面采用紧凑布局：底部保留扫描、使用、跳跃、脉冲和奔跑五个操作按钮，背包、地图和暂停入口位于顶部。发现提示缩为通知条，点击“查看记录”可阅读完整图鉴。

电脑与手机连接同一个 Wi-Fi，双击 **Launch Mobile Preview.command**，然后在手机 Chrome 中打开终端显示的局域网地址。电脑和服务器需保持运行。

同一个游戏会自动显示触屏操作，无需先选设备。用摇杆移动，用另一只手指滑动画面调整视角，长按“扫描”，轻点“使用”收集补给或修复探针。设置中可以调整摇杆位置、按钮大小、滑动灵敏度、画质和小地图。横屏能留出更多画面空间。

已完成 iPhone 和 Android 的浏览器模拟检查，实际手机性能仍需在设备上体验确认。各浏览器和网址分别保存进度；跨设备时请导出并导入存档。
